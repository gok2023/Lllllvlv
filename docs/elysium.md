# Elysium 视觉主题

Elysium 只影响 Freebo 自有窗口。首页使用画作全幅铺底，左侧文学标题、窄幅服务器列和右侧独立操作区；浏览器外壳保持固定 40px 标签条与 48px 工具条。服务器行继续使用原有打开与编辑操作。设置页、选服务浮窗和播放浮窗继承深色纸墨调色板；媒体服务器网页保持原样。观影统计 iframe 沿用原有结构，屏幕阅读表面使用独立的 Elysium 样式，Original 与打印不受影响。

基色为炭黑 `#171c20`、灰青 `#344747` 和纸白 `#eee8da`，朱红 `#c86549` 用于强调。标题使用 Georgia／宋体衬线，正文仍使用系统字体。`art`、`content`、`control` 三类表面按所选画作的固定预设调整透明度与色调；内容与操作区分别使用约 4px 和 2px 的局部轻微模糊。画作没有全屏模糊或图片切换动画。

设置页只在设置布局内加轻度暗层；居中的内容 section 自身携带向边缘消散的局部径向暗部，随实际面板大小变化。统计页的面板、卡片、图表、表格与控件使用稳定深色底和高对比文字，背景画作仍在间隙可见。两处均只对局部表面模糊，不对整幅画作做模糊处理。

五张画作从用户本机同名 PNG 复制到 `public/themes/elysium/backgrounds/`，依次为 Skyline、Church、Conquest、Ruud、Thought Cabinet。每张原图 3840×2160，约 4.9–18.1 MB，当前保持原始质量。该目录的 `disco-*-wallpaper-4k.png` 被 `.gitignore` 忽略，但 Vite 构建仍会将它们复制进 `dist/`；未取得画作分发许可前，不得公开发布包含它们的构建或安装包。Elysium 使用者需要自行提供相应本地图片。扩展契约和验证边界见 [视觉主题](themes.md)。
